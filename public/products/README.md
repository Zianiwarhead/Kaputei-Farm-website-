# Product images — naming sheet

Drop your background-removed images in **this folder** (`public/products/`).
The site auto-wires them by filename — no code changes needed from you,
just match the names below exactly (lowercase, `.png` or `.webp`).

## Rules

| Purpose | Pattern | Example |
|---|---|---|
| Primary image | `{handle}.png` | `tomato-ketchup.png` |
| Flavour variant | `{handle}-{variant}.png` | `barbecue-sauce-honey.png` |
| Back-label view (hover swap) | `{anything}-back.png` | `tomato-ketchup-back.png` |

- **Format:** PNG or WebP with transparency (background already removed).
- **Size:** ~1200px on the longest side is plenty. Keep each file under ~500 KB if you can.
- **Missing files are fine** — anything not found here keeps using the Shopify CDN image for now.
